# `docs/misc`

This directory is reserved for supporting reference material that does not yet
fit one of the stable documentation categories such as `guides/`,
`architecture/`, `reference/`, or `reports/`.

Use this folder sparingly:

- keep canonical user and developer documentation in the dedicated docs folders
- move recurring topics into a dedicated subfolder once they form a clear theme
- treat files here as auxiliary context, not the primary source of truth for the
  project
