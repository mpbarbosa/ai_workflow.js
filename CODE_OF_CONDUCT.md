# Code of Conduct

This project is committed to a respectful, inclusive, and professional community.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Be respectful in discussions, reviews, and issue threads.
- Focus feedback on ideas, code, and documentation rather than individuals.
- Assume good intent and ask clarifying questions before escalating.
- Share constructive, actionable suggestions when raising concerns.

Examples of unacceptable behavior:

- Harassment, discrimination, or personal attacks.
- Trolling, intimidation, or sustained disruptive behavior.
- Publishing private or sensitive information without permission.
- Abusive language directed at contributors or users.

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and
other project communication spaces.

## Reporting

If you experience or witness unacceptable behavior, open a private maintainer
contact through GitHub or file an issue only if doing so is safe and appropriate.

## Enforcement

Project maintainers may remove comments, close threads, or restrict participation
for behavior that violates these guidelines.
