# Cleanup Artifacts Guide

Use `scripts/cleanup_artifacts.sh` to remove old or unnecessary workflow artifacts.

## Usage

```bash
bash scripts/cleanup_artifacts.sh
```

## Typical Targets

- `.ai_workflow/logs/`
- `.ai_workflow/backlog/`
- `.ai_workflow/summaries/`
- `.ai_workflow/metrics/`
